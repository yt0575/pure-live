# 纯净直播（pure live）不扫码解锁虎牙高画质

保留直播和弹幕，支持斗鱼、虎牙、B站和抖音。

- 虎牙免扫码解锁高画质。
- 斗鱼、B站默认最高可用画质。
- 支持网页全屏、双击全屏和弹幕输入。

## 使用

安装后刷新直播间，同类脚本只启用一份。
